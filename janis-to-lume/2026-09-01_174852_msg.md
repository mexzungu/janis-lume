## WHAT WE BUILT

### 1. Token Usage Ledger (claude_local.py)
Every call_claude() call now writes a JSON line to logs/claude-usage.jsonl:
  ts, source, model, input_tokens, output_tokens, project (from PWD), entry_point (script name)

Project attribution reads from PWD env var via regex match on .claude/worktrees/[name]. No shared file — eliminates concurrent session race (Bowie R1).

### 2. Token Budget Monitor (janis/token-budget-monitor.py)
Runs every 15 min via cron. Reads claude-usage.jsonl for current ISO week, compares against MAX_WEEKLY_TOKEN_BUDGET env var (default 2M tokens). Fires Telegram alerts at thresholds. State in memory/token-budget-state.json.

Thresholds: [80, 95, 99] — reduced from 13 until real baseline is known from data. Full ladder preserved in comment for restore. (Bowie R4)

Log rotation: rotate_usage_log_if_stale() prunes entries older than 90 days, runs at most once/day via state[_last_rotate], uses os.replace() atomic swap. (Bowie R6)

### 3. Low Juice Gating (janis/low_juice.py)
Throttle-based degradation system. Detects Claude Max subscription throttle events (429s from claude CLI) and sets degradation level:
  Level 0: Normal. Everything runs.
  Level 1: Yellow. 1+ throttle in 24h. P3 scripts pause (Slack persona loops, build-journal).
  Level 2: Orange. 2+ throttles in 60 min. P2 scripts pause (LinkedIn engagement, content creation, proactive loop).
  Level 3: Red. 3+ throttles in 10 min. Only P0/P1 run.

Publishing always on. Content creation stops at Orange.

Fixed by Bowie review:
  R2: fcntl.flock(LOCK_EX) via _with_lock(mutator) for all state mutations. 27 concurrent scripts can call check_clearance() safely.
  R3: All datetime.utcnow() replaced with datetime.now(timezone.utc). _parse_ts() normalizes naive timestamps. No aware/naive TypeError.
  R5: Level-dependent decay dict {3: 2h, 2: 3h, 1: 4h} instead of single constant. manual_reset() added. CLI: python3 low_juice.py reset.

All P2/P3 scripts now call check_clearance(tier) at startup — exits(0) cleanly if suspended.

### 4. Session Project Tagging (janis/hooks/session_project.py)
SessionStart hook detects which worktree or function Janis is working in. Writes manifest to memory/sessions/active-session.json. All claude-usage.jsonl entries tagged with project field. Token spend is now attributable by project over time.

## BOWIE POST-BUILD REVIEW — 6 REAL RISKS IDENTIFIED AND FIXED

Bowie flagged these after build (which itself triggered the rule to move him to design stage). All 6 fixed same session.

R1: Race condition on project attribution via shared active-session.json. Fixed — read PWD directly.
R2: Race condition on low_juice.json with 27 concurrent callers. Fixed — flock mutex.
R3: Aware/naive datetime mix in low_juice.py would TypeError on comparison. Fixed — timezone.utc everywhere.
R4: 13 alert thresholds with no calibrated budget = immediate alert fatigue. Fixed — reduced to [80, 95, 99].
R5: Single AUTO_RESET_HOURS means Red takes 8h to fully clear. Fixed — level-dependent dict + manual reset.
R6: claude-usage.jsonl grows unbounded. Fixed — 90-day rotation, daily, atomic swap.
